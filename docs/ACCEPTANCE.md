## 已验收的产品流程

- 上传真实照片、切换预设比例、EXIF 方向校正与自动拼接。
- 自由裁剪窗口：自由/锁定比例、边角调整、鼠标和模拟触控拖动、键盘微调、缩放、取消、重置与重新打开；更换底图重置选区。
- 选区像素在作品预览、AI 预览和原生尺寸 PNG 导出中保持一致；裁剪草稿不会改变作品或清空推荐，应用后不自动请求模型。
- 八种内置形状、色板、自定义 HEX、上传纹理色纸、提取主色。
- 两套独立布局、数量和孔径调整、碎片聚拢、旋转与重叠设置、独立重排。
- 外围色纸拼接：可调等宽纯色区域、沿外围散落或环绕排列、纹理上传提取主色，碎片不侵入中央照片、不越出外边界。
- 在上下、左右、交换顺序与外围模式下直接拖动孔位，其他孔位和碎片排列不变；触控、方向键、Esc 取消、恢复自动孔位和改变行数重新排列。
- 拖动后原孔位恢复照片，新孔位填色，对应碎片内容随源位置更新；PNG 导出保留手动位置，辅助选中线不参与渲染。
- 色纸上的照片碎片也可独立拖动：覆盖上下/左右两种顺序和外围拼接、触控与键盘、Esc/触控取消、恢复自动排列、重排和孔数变化。照片源孔不动，其他碎片与旋转保持不变，采用新推荐不清除手动碎片位置。
- 移动纯色色纸上的碎片后，原目标位置恢复底色，新目标位置保留相同源像素，照片画布保持不变；完整作品及单独色纸 PNG 均保留手动目标位置。
- 完整双联与单幅 PNG 导出，输出尺寸与选择一致。
- 外围作品、照片和色纸可独立导出；外围色纸中央透明，照片 1024 × 1024、外围宽度 28% 时完整作品为 1598 × 1598。
- DeepSeek 缺失字段补全、候选采用、保留用户选择、失败后手动制作及内置灵感。
- 颜色/色纸与形状分别清空、重复点击取消、一键清空两项后仅发送底图；只有手动生成/重试才请求模型。
- 上传、编辑、清空、采用候选和内置灵感均不自动调用模型；连续点击生成只产生一次请求，改变裁切使旧候选失效但不重新请求。
- 采用推荐后保留三组候选、标记当前方案，反复切换和切回原方案时画布正确还原且不增加请求；仅推荐颜色/形状时，生成前锁定的形状/颜色/纹理保持不变。主动重新生成沿用原补全范围。
- 燕子按用户新提供的侧飞剪影重绘为矢量蒙版，保留弧形翼与细长叉尾；蒙版仅包含鸟形，不包含白底、水印或编号，图标、画布和导出共享同一路径。
- 窄屏布局、无横向溢出、帮助对话框。
- LLM 配置窗口：DeepSeek/兼容服务、API 根地址、模型名、密钥保存/保留/清除、失败提示、关闭丢弃草稿、窄屏交互。
- 配置持久化、限制性权限、修订冲突、写入失败保留原配置、坏文件拒绝加载；更换地址须重输密钥，清除不回退旧环境密钥。
- 配置 API 不回显密钥、不调用模型；兼容模式正确发送图片、模型名和新密钥，删除厂商专有参数，配置变化后不复用旧缓存。

## 自动化检查

| 检查              | 覆盖                                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| TypeScript        | 严格模式、索引访问、无未使用变量                                                                       |
| ESLint / Prettier | 代码规范、Hooks 规则、统一格式                                                                         |
| 单元与 HTTP 测试  | 最优裁切、确定性种子、边界与碰撞、孔数守恒、锁定字段、形状白名单、非法图片、缓存、同源与请求验证       |
| 浏览器交互测试    | 上传、EXIF、比例、独立重排、锁定参数、迟到的推荐响应、服务失败、纹理模式、导出和窄屏                   |
| 浏览器像素测试    | 源像素准确转移、眼睛内部空隙保留、原色纸回填、纹理旋转后的双向交换、孔位移动后的像素更新与外围透明导出 |
| 生产构建与启动    | 浏览器构建、Node 服务构建、生产健康检查                                                                |
| 密钥隔离          | 扫描前端 JS/CSS/HTML/Source Map；检查生产 HTTP 不暴露 `.env.local`                                     |

浏览器常规测试使用模拟模型响应，CI 不产生模型费用，也不需要真实密钥。交互测试统一拦截推荐接口，避免遗漏模拟时意外调用真实服务。此次配置与发布回归没有调用真实模型 API。配置测试也使用模拟接口或临时目录，不修改开发者的真实密钥。基础测试使用合成图片，可在没有私人素材的环境运行。

外围几何测试覆盖九种预设比例、4/16/80 个孔、10%/28%/60% 外围宽度及环绕/散落布局，验证边界、中央区域避让和不重叠约束。交互测试验证采用推荐后拖动孔位仍保留候选且不增加请求。

手动目标位置测试验证不同宽度和比例下的外边界、中央照片避让、单个目标移动与源孔独立性；目标位置按色纸尺寸归一化，比例/拼接变化后仍满足边界约束。

## 真实 DeepSeek 联调

使用当前配置的 `deepseek-flash`，在应用界面选择夜景测试底图和星芒形状，并将底色交给模型推荐。界面收到三组配色：深靛蓝、青绿与亮黄；说明分别引用了夜空/玻璃反光、霓虹与暖黄对比、广告牌高光。已选星芒保持不变，结果只包含缺失的颜色。

此前独立脚本还验证了参考图的视觉识别及三组形状/配色 JSON。本地历史报告及参考图均不随仓库发布；这些付费联调不属于 CI 或首次启动流程。

## 当前明确边界

- 当前会话的图片与设置不持久化，刷新页面会重置；帮助界面已说明。
- 支持手动矩形裁剪，不包含人脸/主体识别裁剪、透视校正或任意角度旋转底图。
- 上限 30 MB / 5000 万像素，照片导出长边最高 4096；完整外围作品尺寸还包含四周扩展区域。高分辨率导出仍在浏览器主线程执行。
- 自动孔位避免重叠，手动孔位允许重叠；改变孔位布局或数量会恢复自动位置。手动位置随比例/裁剪保持相对位置，图片替换时重置。
- 手动碎片允许重叠，调整碎片布局、散布范围、重叠设置或孔数时恢复自动排列；外围模式限制在色纸内，不能拖入中央照片。
- 自动化浏览器覆盖 Chromium；尚未声称覆盖 Safari、Firefox 或实体移动设备。
- 本地单进程版本，无账号及多租户配额；默认只监听回环地址，不包含公开部署。
- LLM 配置在本机持久化，图片与编辑状态仍不持久化；配置文件是限制权限的本地明文文件，不是加密保险库。
